### About

I am a software engineer who enjoys turning complex product ideas into reliable, production-ready systems.  
My work sits at the intersection of **enterprise full-stack development** and **practical AI engineering**.

I care about clean architecture, maintainable code, and shipping features that users can actually trust — whether that means a multi-tenant web platform, a polished Angular/React interface, or an LLM-powered assistant grounded in real application data.

**What I bring to the table**

- End-to-end ownership from API design and data modeling to UI delivery and cloud deployment
- Strong fundamentals in **C# / ASP.NET Core** and **Python / Django**
- Hands-on comfort with **LLM APIs**, **RAG pipelines**, and applied **machine learning / computer vision**
- A delivery mindset: CI/CD, Docker, Azure, and clear collaboration through GitHub and Agile practices

### Engineering Approach

I prefer building software that stays understandable after the first release.

- **APIs first** — clear REST contracts, consistent validation, and secure authentication / authorization
- **Data with intent** — relational modeling, Entity Framework / ORM discipline, and schemas that scale with the product
- **UI that supports the workflow** — not just screens, but usable flows for admins, users, and operators
- **AI that is useful** — model features around real user questions and grounded application context, not demos only
- **Ship with confidence** — Dockerized environments, automated pipelines, and practical testing with tools like Postman
